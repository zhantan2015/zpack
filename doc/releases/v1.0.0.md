# zpack v1.0.0

首个正式版本。zpack 是一个用 Zig 编写的命令行压缩工具，当前支持 RLE 算法与自有的 `.zpack` 容器格式。

---

## ✨ Highlights

- **简洁的 CLI**：`zpack [-a <algorithm>] <-c|-d> <input> [output]`
- **自有容器格式** `.zpack`：包含 magic、version、original_size、payload、CRC32 校验与 EOF 标记
- **流式编解码**：基于 RLE，读写全程走流式，避免一次性载入大文件
- **原子写入**：输出文件使用 `createFileAtomic` + `finish` 提交，杜绝半成品文件
- **统一测试入口**：`zig build test` 一键跑全部单元测试
