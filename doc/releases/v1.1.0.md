# zpack v1.1.0

新增 LZ77 压缩算法。zpack 现在支持两种算法：RLE 和 LZ77，通过 `-a` 显式选择。

---

## ✨ Highlights

- **LZ77 算法支持**：`-a lz77` 启用，适合有重复片段的数据
- **与 RLE 并存**：`-a rle` 仍是缺省，两种算法的 `.zpack` 容器格式统一
- **向后兼容**：v1.0.0 生成的 `.zpack` 文件可被本版本直接解码
- **CRC 一致性**：两种算法均输出原始数据的 CRC32，解码端校验
- **重叠复制正确性**：LZ77 解码器正确处理 `offset < length` 的自引用（RLE 退化场景）
- **跨缓冲边界**：解码器在 4KB 输出缓冲 flush 时保留最近 255 字节历史，保证跨边界引用

---

## 🚀 Usage

```text
zpack [-a <algorithm>] <-c|-d> <input> [output]

  -a <algorithm>   压缩算法，可选 rle / lz77，缺省 lz77
  -c               压缩模式
  -d               解压模式
  <input>          输入文件路径
  [output]         输出文件路径（可选）
